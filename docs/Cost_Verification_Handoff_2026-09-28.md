# 비용 파트 검증 인수인계 (2026-09-28)

**이 문서를 받는 사람에게**: 비용 화면·수집 기능이 `main`에 전부 들어갔습니다(#136·#137, 그리고
조은솔님의 #138). 자동 테스트(백엔드 1111개)는 통과했지만, **사람이 브라우저에서 눈으로 봐야만
알 수 있는 것**과 **실제 클라우드를 호출해야 알 수 있는 것**이 남아 있습니다. 이승현은 발표 자료를
준비하므로, 아래 A·B·C를 나눠서 봐 주세요.

> 문제를 발견하면 고치지 말고 **§6 양식대로 기록만** 해 주세요. 수정은 이승현이 합니다.

## 2. 파트 A — 브라우저에서 눈으로 볼 것 (16건)

각 항목은 **위치 → 할 일 → 통과 → 실패 시 기록**입니다. 통과하면 §6 표에 `O`만 적어 주세요.

### A-1. 모달·이동·상태 (예전부터 미뤄둔 것)

**A1. 미지정 대상 목록**
- 위치: ① 비용 개요 탭 → 상단 카드 중 "미지정"이라고 적힌 카드
- 할 일: **"미지정 대상 보기"** 버튼 클릭
- 통과: 모달이 열리고 ①표의 행 수가 카드에 적힌 개수와 같다 · "정가표에 없음" 문구가 보이는 행이
  있다 · "인벤토리에서 보기"를 누르면 인벤토리 화면으로 이동한다
- 실패 시: 카드 숫자와 모달 행 수를 각각 적고 모달 캡처

**A2. 좁은 창에서 표가 넘치지 않는지**
- 위치: ① 탭 → 서비스 상세 모달, ② 미지정 모달 (둘 다)
- 할 일: 브라우저 창을 **폭 500px 정도로 줄인 뒤** 모달을 연다
- 통과: 표가 **모달 안에서만** 좌우로 스크롤된다. 페이지 전체가 좌우로 밀리지 않는다
- 실패 시: 어느 모달인지 + 캡처

**A3. 뒤로 가기**
- 위치: ① → ③ 탭으로 이동하고, 기간·CSP 필터를 몇 번 바꾼 뒤 브라우저 **뒤로 가기**
- 통과: 주소창 URL과 화면(탭·필터)이 서로 맞는다
- 실패 시: 뒤로 가기 직전 URL과 직후 URL, 화면 상태를 적기

**A4. 검토 목록 상태 전환**
- 위치: ③ 예산·검토 탭 → 비용 검토 목록
- 할 일: 상태 버튼(열림 / 해결됨 / 전체)을 빠르게 번갈아 누른다
- 통과: 표가 심하게 깜빡이지 않고, 로딩 중에는 "조회 중" 같은 안내가 짧게 보였다 사라진다
- 실패 시: 화면 녹화나 캡처 + 어떤 순서로 눌렀는지

**A5. 조건 링크 복사**
- 위치: ① 탭 상단 필터 영역 → **"이 조건 링크 복사"**
- 할 일: 클릭 → 브라우저가 클립보드 권한을 물으면 허용 → 새 탭에 붙여넣기
- 통과: 복사된 URL을 새 탭에서 열면 **같은 기간·같은 필터**로 화면이 뜬다
- 실패 시: 권한 팝업이 떴는지, 붙여넣기 결과가 무엇이었는지 적기

**A6. 다크 테마 대비**
- 위치: 왼쪽 사이드바 맨 아래 테마 토글 → 다크로 전환 후 ①②③ 탭 훑기
- 통과: 그룹 제목·배지·표 맨 뒤의 `—`(값 없음) 행이 배경에 묻히지 않고 읽힌다
- 실패 시: 안 읽히는 부분 캡처(다크 상태로)

**A7. A4 인쇄**
- 위치: ① 탭에서 `Cmd/Ctrl + P` → 대상 "PDF로 저장", 용지 A4
- 통과: 표·카드가 페이지 경계에서 잘리지 않고, 빈 페이지가 끼지 않는다
- 실패 시: 저장한 PDF를 첨부하고 몇 페이지에서 잘렸는지 적기

**A8. 대시보드 카테고리 카드**
- 위치: 대시보드 화면(`dashboard.html`)
- 통과: 카테고리별 비용 카드가 **"추정치"가 아니라 실측 값**으로 보인다
- 실패 시: "추정치" 문구가 남아 있으면 캡처 (조은솔님 담당 화면)

**A9. 인벤토리 이동 문구**
- 위치: ① 탭 → 계정 표의 "인벤토리에서 보기" 계열 링크
- 통과: 눌렀을 때 인벤토리로 이동한다. 지금은 **계정 필터가 자동 적용되지 않는 것이 정상**이며
  문구도 그렇게 적혀 있다
- 실패 시: 문구와 실제 동작이 어긋나면 캡처 (조은솔님 패치 후 문구를 되돌릴 예정)

### A-2. 이번 라운드에 새로 생긴 문구 (자동 확인만 됨)

> 배경: Azure·GCP는 "이 날 비용이 다 도착했는지"를 알려 주지 않습니다. 그래서 **금액은 그대로

> 읽히는지 보는 항목입니다. 데모 계정은 AWS만 있어 일부는 문구가 안 나올 수 있는데, 그때는

**A10.** ① 탭 계정 표(CF-009)·누적 카드(CF-002) — 근거가 부족한 계정이 **"N일 금액 관측 · 범위

**A11.** ① 탭 CF-030 — **"마지막 수집 0건"** 과 **"조회 기간 0원"** 을 구분해서 설명하는지.
둘을 같은 말로 뭉뚱그리면 실패.

**A12.** ① 탭 CF-003(월말 전망) — 전망이 보류될 때 **"수집 실패"가 아니라 "도착 범위를 알려주지

**A13.** ③ 탭 CF-026(예산 대비 실적) — 보류 상태에서도 **받은 금액은 보이고 소진율만 없는지**.
금액까지 사라지면 실패.

**A14.** ③ 탭 CF-033(급증 탐지) — 보류 사유가 **"수집 범위 근거 부족"** 과 **"기준선 미수집"** 으로
갈려 보이는지. 배지와 그 아래 "평가하지 못한 계정 사유" 목록 **둘 다** 확인.

**A15.** 마이페이지(`mypage.html`) — GCP 계정 행의 상태 표기. 이번에 GCP 수집기가 생겨
**"미지원" → "연결 안 됨"**(데모 GCP 키가 검증 실패 상태라서)으로 바뀝니다. 발표 화면에 이렇게
보여도 되는지 판단용이라, **보이는 그대로 캡처**만 남겨 주세요.

**A16.** 알림함(사이드바 종 아이콘) — 비용 수집 실패 알림이 있으면 문구가 읽히고, 클릭 시 비용
화면으로 이동하는지.

## 3. 파트 B — 실제 클라우드를 호출하는 검증 (계정 소유자 + 이승현 동석)

> **모두 실제 요금이 발생합니다.** 혼자 진행하지 말고 이승현에게 알린 뒤 함께 하세요.
> 상한(호출 횟수·스캔량)은 코드로 걸려 있지만, **실패해도 재시도하지 말고 그대로 기록**합니다.

**B1. Azure 실수집** (Azure 구독 소유자)
1. Azure 포털 → 해당 구독 → **액세스 제어(IAM)** → 우리 앱(서비스 주체)에 **Cost Management
   Reader** 역할 부여 (전파에 수 분)
2. 마이페이지 → 그 Azure 자격증명 행 → **재검증** 1회
   - 통과: 상태가 "검증됨"으로 바뀐다
   - 실패: 화면 문구와 `backend/logs/app.log`의 `credential.verify.failed` 줄(단계·HTTP 상태)을 복사
3. 이승현이 격리 환경에서 **제한 수집 1회**(UTC 3일치, 페이지 2, HTTP 요청 3회 상한) 실행
   - 통과: 수집된 금액이 Azure 포털의 **같은 구독·같은 기간·Actual cost·원통화·Usage 분류** 합계와
     맞는다. 표시 반올림(소수 2자리)과 저장 정밀도(6자리) 차이는 정상

**B2. GCP 실수집** (GCP 결제 계정 소유자)
1. 결제 계정 → **BigQuery로 비용 내보내기(표준 사용량)** 가 켜져 있고 데이터가 쌓였는지 확인
   (켠 시점 이후 데이터만 쌓이며 보통 하루 걸립니다)
2. 서비스 계정에 권한 부여: 쿼리를 돌릴 프로젝트에 **BigQuery 작업 사용자**, Export 데이터셋에
   **BigQuery 데이터 뷰어**
3. Export 테이블 경로(`프로젝트.데이터셋.gcp_billing_export_v1_...`)를 이승현에게 전달 → 등록 후
   수집 1회
   - 통과: 계정 상태가 **"설정 필요" → 정상**으로 바뀌고 금액이 GCP 콘솔과 맞는다
   - 참고: 실행 전 dry-run이 "얼마나 스캔할지"를 먼저 알려 주고, 상한을 넘으면 실제 쿼리를 보내지
     않습니다

**B3. AWS 재수집 1회** (AWS 계정 소유자 / 이승현)
- 위치: ① 탭 계정 행의 **"다시 수집 요청(과금 가능)"**
- 통과: 성공하면 "마지막 수집" 시각이 갱신되고, 실패하면 **실패 알림**이 알림함에 남는다 ·
  같은 계정을 1시간 안에 다시 누르면 제한 안내가 뜬다
- 이 경로는 **한 번도 실행된 적이 없습니다.** 실패 알림·건너뜀 사유·1시간 제한을 실제로 보는 것이
  목적입니다

**B4. 자격증명 실패 문구** (아무 CSP나, 틀린 키로)
- 위치: 마이페이지 → Azure 또는 GCP 자격증명 등록/수정에 **일부러 틀린 값** 입력 후 저장
- 통과: 실패 안내에 **"AWS"라는 단어가 없고** 해당 CSP(Azure/GCP) 기준의 확인 항목이 적혀 있다
- 실패 시: 문구 전체를 캡처

## 4. 파트 C — 코드·정책 확인 (조은솔 / 안권형)

### 조은솔님
1. **자격증명 영역 파일 2개 리뷰** — `app/providers/azure.py`(검증 실패를 payload/token/subscription
   단계로 나눠 **로그만** 추가, 반환 계약 불변) · `app/routers/credentials.py`(CSP별 실패 문구).
   합의 전에 들어간 변경이라 사후 확인 부탁드립니다. 배경:
   `docs/Azure_Credential_Verify_Diagnostics_2026-09-26.md`
2. **전망(월말 예상) 계약 확정** — 수집 누락이 있을 때 "보류"(현재 구현) vs "계산하고 안내"(#128).
   지금은 보류로 되돌아가 있습니다
3. **`partial_success` 어휘 통일** — 비용에서는 "저장 0건", 동기화에서는 "일부 성공"으로 **의미가
   반대**입니다. 이번에 비용 쪽은 "받다가 끊긴 경우"로 범위를 좁혔고, 최종 정리는 남아 있습니다
4. **`inventory.html`의 `?cloud_account_id=`** 지원 여부 — 되면 비용 화면의 이동 문구를 되돌립니다
5. **데모 시딩의 GCP 자격증명**(`verified=false`)을 그대로 둘지 — A15와 연결됩니다
6. **대시보드 카테고리 카드**가 실측으로 잘 보이는지(A8과 같은 항목)

### 안권형님
7. **카테고리 매핑 단일화** — `app/report_cost.py`와 `app/cost/query.py`에 같은 표가 두 벌입니다
8. **`report_email.py`의 통화 혼합 합산** — KRW와 USD를 그대로 더하고 있습니다
9. **`/cost-reports/*` 부품 3종 계약** — 필요한 데이터·기간·집계 단위가 정해지면 구현 범위를 잡습니다

## 7. 참고 — 명령어

```bash
# 원본 스택
docker compose up -d
docker compose stop api        # 자동 수집(15:00 KST)을 피하고 싶을 때

# 격리 검증 환경(원본 DB·스택을 건드리지 않음 — 실수집 때 이승현이 사용)
sh scripts/verify_profile.sh up
VERIFY_DOCKER_CONTEXT=colima-verify VERIFY_NET=mcp-verify-net \
  VERIFY_DB_HOST=mcp-db-verify VERIFY_IMAGE=mcp-verify-api:local sh scripts/verify_stack.sh up
VERIFY_DOCKER_CONTEXT=colima-verify sh scripts/verify_preflight.sh blocked   # 수집 차단 상태 확인
sh scripts/verify_profile.sh stop

# 백엔드 테스트(코드를 고쳤을 때)
cd backend && TZ=UTC DATABASE_URL="postgresql+psycopg2://mcp_user:<비밀번호>@localhost:5432/mcp_db" \
  .venv/bin/python -m pytest -q
```
