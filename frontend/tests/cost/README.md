# 비용 화면 DOM 회귀 테스트

`cost.html`을 jsdom으로 띄우고 **fetch를 가로채** 서버 응답을 주입한 뒤, 화면에 실제로 그려진
글자를 확인한다. 서버·DB·네트워크·브라우저를 쓰지 않는다(더미 세션 값만 `localStorage`에 넣는다).

```
cd frontend/tests/cost
npm install        # jsdom만 받는다
npm test           # = node coverage_basis.test.js
```

## 무엇을 고정하나

`coverage_basis.test.js`는 **수집 근거(coverage_basis) 도입 라운드에서 실제로 났던 화면 회귀**만
담는다. 각 케이스는 고치기 전 코드에서 실패하는 것을 확인하고 남겼다.

- 금액은 보이되 판정만 보류한다(전망·기간 비교·예산 소진율·급증).
- "마지막 수집 0건"과 "조회 기간 0원"을 구분한다.
- AWS(`complete_range`)의 기존 문구는 그대로 유지된다(회귀 방지).
- 보류 사유를 뭉뚱그리지 않는다 — 배지와 계정별 상세 줄 **둘 다** 사유별로 갈린다.

## 한계 — 이 테스트가 대신하지 못하는 것

jsdom은 레이아웃·실제 렌더링·실 브라우저 동작을 검증하지 않는다. 화면 확인은 별도로 브라우저에서
해야 하고, 이 파일이 통과했다는 사실을 "브라우저에서 확인했다"로 쓰지 않는다.
